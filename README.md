# rock-paper-scissors-game
✊ Rock Paper Scissors 🎮

A simple and interactive Rock Paper Scissors game built using Python. The player competes against the computer, and the computer randomly selects Rock, Paper, or Scissors for each round.

📌 About the Game

Rock Paper Scissors is a classic hand game played between two players. In this Python version:

- 🪨 Rock beats Scissors
- 📄 Paper beats Rock
- ✂️ Scissors beats Paper
- If both players choose the same option, the round is a Draw

🚀 Features

- Simple and beginner-friendly Python code
- Player vs Computer gameplay
- Random computer choices
- Automatic winner determination
- User-friendly command-line interface
- Input validation

🛠️ Technologies Used

- Python 3
- "random" module

▶️ How to Run

1. Make sure Python is installed on your computer.
2. Clone or download this repository.
3. Open the project folder in Terminal or Command Prompt.
4. Run:

python rock_paper_scissors.py

5. Choose Rock, Paper, or Scissors and play!

🎮 How to Play

When the game starts, enter one of the following:

Rock
Paper
Scissors

The computer will randomly choose its option, and the game will display the result.

Example

Choose Rock, Paper, or Scissors: Rock

You chose: Rock
Computer chose: Scissors

🎉 You Win!
